Discord music quiz bot written in Rust with `poise`, `serenity`, and `songbird`.

Jasper plays short music preview clips from a public Spotify playlist, lets people guess the artist or track name in Discord, and keeps score across rounds.

## Commands

- `/music_quiz <spotify_playlist_url> [total_rounds]`
- `/ping`

## What you need

Before running the bot yourself, you need:

- a Discord bot application and bot token
- a Spotify application with client credentials
- a server where the bot can register commands and join voice channels

Discord-side setup:

- enable the `MESSAGE CONTENT INTENT` for the bot
- invite the bot with permissions to:
  - view channels
  - send messages
  - connect to voice
  - speak
  - use application commands

Spotify-side setup:

- create an app at Spotify Developer Dashboard
- copy the client id and client secret

## Configuration

The bot reads configuration from environment variables. A local `.env` file works in development.

Required variables:

```env
ENVIRONMENT=development
SPOTIFY_CLIENT_ID=...
SPOTIFY_CLIENT_SECRET=...
DISCORD_TOKEN=...
DISCORD_TESTING_GUILD_ID=...
```

Notes:

- `ENVIRONMENT` accepts `dev` / `development` and `prod` / `production`
- `DISCORD_TESTING_GUILD_ID` is required in development mode so slash commands register in one guild
- in production mode, commands register globally instead
- legacy `TESTING_GUILD_ID` is also accepted in development mode

## Running with Nix

This repository includes a Nix dev shell with the native dependencies needed by the voice stack.

Validate the project:

```bash
nix develop -c cargo check
```

Run the bot:

```bash
nix develop -c cargo run
```

If you prefer an interactive shell first:

```bash
nix develop
cargo run
```

The dev shell currently provides:

- `cmake`
- `libopus`
- `pkg-config`

## Running without Nix

You can also build with a normal Rust toolchain, but you need the native audio dependencies available on your system. At minimum, the current build expects tools and libraries equivalent to:

- `cmake`
- `pkg-config`
- `opus` / `libopus`

## Development vs production

Development mode:

- registers slash commands only in `DISCORD_TESTING_GUILD_ID`
- updates commands quickly while you iterate

Production mode:

- registers commands globally
- command propagation can take longer on Discord's side

## How the quiz works

1. A user starts `/music_quiz` with a public Spotify playlist URL.
2. The bot loads tracks from Spotify.
3. It resolves previewable snippets through iTunes.
4. It joins the caller's voice channel.
5. Players guess in text chat while the preview plays.
6. The bot posts round results and a final leaderboard.

## Deployment notes

- The bot must be able to join the same voice channel as the player starting the quiz.
- The playlist should be public.
- Not every Spotify track has a usable preview clip through iTunes, so some playlists may not be suitable.
- If there are too few previewable tracks, the quiz will fail before starting.
